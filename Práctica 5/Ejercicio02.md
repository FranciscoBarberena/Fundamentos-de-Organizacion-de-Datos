# Ejercicio 2

- La función de dispersión recibe una clave primaria. Si esta no es un número, se transforma en uno a través de un criterio arbitrario ya definido (ej: el ASCII de los char de un string). Luego, se le aplican ciertas operaciones predefinidas al número, con la esperanza de generar un número aleatorio para así generar una distribución uniforme de las claves para minimizar las colisiones (en realidad es pseudo-aleatorio, ya que si se le aplica la función al mismo número 10000 veces, siempre dará el mismo resultado). Finalmente, a ese número se le aplica la operación de módulo con la cantidad de buckets del disco secundario que fueron reservados al archivo , para asegurarse de que la dirección exista realmente. Por ejemplo, si el disco tiene 5000 buckets reservados para un archivo, y la función de hashing dio 8000, se haría la cuenta 8000 mod 5000 = 3000, y 3000 sería el sector asignado a la clave recibida (si nos hubiesemos quedado con el 8000, no habría bucket con ese número).
